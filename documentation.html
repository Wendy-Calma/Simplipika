API Test Results

The following screenshots demonstrate successful endpoint testing and data validation for the system.

GET /admin/residents

Retrieves a comprehensive list of all registered residents for administrative review.

GET /admin/programs

Fetches all active programs and community initiatives currently available.

POST /admin/incidents

Creates a new incident report entry with timestamp and descriptive data.

PATCH /admin/residents/{id}

Updates specific fields of an existing resident record via partial modification.

DELETE /admin/residents/{id}

Permanently removes a resident record from the system database.
